High Street Gym Website

This is a full-stack responsive web application built for High Street Gym, a Brisbane-based health and fitness company. The project was developed as part of a TAFE assignment across three main phases — backend development, mobile-first frontend, and full-stack integration.

  

📌 Project Overview

High Street Gym is a 24/7 gym with multiple locations across Brisbane. The business required a modern website to:

- Allow members to log in and book fitness classes
- Manage gym staff and class schedules
- Enable members to post in a shared blog
- Provide administrators with full management tools
- Offer a responsive design for both desktop and mobile

  

💻 Features

✅ Phase 1 – Backend Website with Database

- User authentication (member, trainer, admin)
- Class bookings via calendar view
- Member blog with post/delete permissions
- Full CRUD for users, posts, classes, and bookings
- Secure database integration (SQL)

📱 Phase 2 – Mobile-First Frontend (Proof of Concept)

- Frontend built with a modern framework (e.g., React/Vue)
- Responsive design for mobile
- Functional navigation without backend integration

🔗 Phase 3 – Full-Stack Integration + XML Import

- Connect frontend and backend systems
- Import activities.xml and locations.xml into the database

  

🧠 Technologies Used

- HTML5 / CSS3 / JavaScript
- Backend: Node.js / Express.js
- Frontend: React
- Database: MySQL
- Authentication: JWT
- XML Parsing: Custom import tools
